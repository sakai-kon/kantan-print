# 🖨️ かんたん印刷

スキャンした画像やPDFに文字を入れて、そのまま印刷するためのシンプルなWebアプリです。

## 現在の初期実装

- 画像（JPG / PNG / WEBP）の読み込み
- PDFの読み込み（現在は1ページ目）
- 画像の回転
- 表示サイズの変更
- 文字の追加・ドラッグ移動・文字サイズ変更
- Windows / ブラウザ標準の印刷ダイアログを利用した印刷
- ドラッグ＆ドロップ

## 今後追加する機能

- ✂️ トリミング
- PDFの複数ページ対応
- 文字の編集・削除をもっと分かりやすくする
- 明るさ・コントラスト・白黒などの画像補正
- 用紙サイズや印刷倍率の分かりやすい設定
- Undo / Redo
- より大きく分かりやすい「おじいちゃん向け」UI

## GitHub Pages

`main` ブランチをGitHub Pagesの公開元に設定するとブラウザから利用できます。

このアプリは基本的にブラウザ内でファイルを処理するため、スキャンした書類を外部サーバーへアップロードする構成にはしていません。
