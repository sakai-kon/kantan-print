# 🖨️ かんたん印刷

スキャンした紙を簡単に編集したり、白紙から必要最低限の文書を作ったりして、そのまま印刷するWebアプリです。

## モード

### 📄 スキャンした紙を編集
JPG / PNG / WEBP画像やPDFを開いて、切り取り、回転、明るさ、コントラスト、白黒化、文字追加ができます。複数ページPDFにも対応しています。

### 📝 白紙から文書を作る
A4 / A5 / B5の白紙ページを作り、文字を何個でも追加できます。画像もページに配置でき、移動・サイズ変更ができます。簡単なお知らせ、メモ、案内、資料などを作る用途を想定しています。

## 主な機能

- 画像 / PDF読み込み
- PDFの複数ページ対応
- 白紙文書モード
- 文字追加、移動、編集、削除
- 文字サイズ、色、太字、斜体、下線、左/中央/右寄せ、縦書き
- 文字入力中のリアルタイムプレビュー
- 画像追加、移動、サイズ変更
- ページ追加とページ移動
- A4 / A5 / B5、たて / よこ
- トリミング
- 回転
- 大きさ変更
- 明るさ / コントラスト / 白黒
- Undo / Redo、Ctrl+Z / Ctrl+Y
- 印刷プレビュー
- Windows / ブラウザ標準の印刷ダイアログ

## 個人書類について

画像・PDFは基本的にブラウザ内で処理し、アプリ独自のサーバーへアップロードする構成にはしていません。PDF表示にはPDF.jsをCDNから読み込みます。
