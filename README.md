# 🖨️ かんたん印刷

スキャンした画像やPDFに文字を入れて、そのまま印刷するためのシンプルなWebアプリです。

## できること

- 画像（JPG / PNG / WEBP）の読み込み
- PDFの読み込みとページ移動（複数ページ対応）
- ドラッグ＆ドロップでファイルを開く
- ✂️ マウスで範囲を選ぶトリミング
- 🔄 90度回転
- 📐 25〜200%の大きさ変更
- ☀️ 明るさ・コントラスト調整
- ⚫ 白黒化
- 🔤 文字の追加、移動、編集、削除
- 文字サイズ・色・太字・縦書き
- ↶ Undo / ↷ Redo（キーボード操作にも対応）
- 🖨️ Windows / ブラウザ標準の印刷ダイアログ
- PDFの全ページをまとめて印刷
- スキャンした書類を基本的にブラウザ内で処理
- Web App Manifest付きで、対応ブラウザではアプリのように登録可能

## 使い方

1. `ファイルを選ぶ` からスキャンした画像またはPDFを開きます。
2. 文字を入れたり、切り取ったり、明るさなどを調整します。
3. 必要なら前後のページを移動します。
4. `🖨️ 印刷する` を押すとWindows / ブラウザ標準の印刷画面が開きます。

## GitHub Pages

`main` ブランチをGitHub Pagesの公開元に設定すると、ブラウザからURLで利用できます。

```text
https://sakai-kon.github.io/kantan-print/
```

PDFの読み込みにはPDF.jsをCDNから読み込みます。スキャンした画像そのものをこのアプリのサーバーへアップロードする仕組みにはしていません。
